    SheetStyle dataclass ¶

    Visual parameters of a TableSheet.

    Every field can be changed with TableSheet.config_layout (or with the shortcut subplots_adjust) and passed as a keyword argument of the TableSheet constructor.

    Size

    font_family : str Font of titles, notes and sources. A comma-separated list is accepted; the first installed font is used, with a fallback to DejaVu Sans. width_in : float Image width in inches. height_in : float | None Image height in inches. None (default) computes it from the content. When set, the image has exactly this height: the source lines are anchored to the bottom, panels that do not fit are scaled down keeping their proportions, and free space is distributed according to valign. For a 16:9 slide use width_in=13.33, height_in=7.5. valign : {"top", "center", "bottom"} Where the panels sit when height_in leaves free space. dpi : int Resolution of rendered tables and of the exported image.

    Spacing (subplots_adjust semantics)

    The panels live in a grid. left, right, bottom, top, wspace and hspace work like matplotlib.pyplot.subplots_adjust. None means automatic and falls back to the inch-based values.

    left, right : float | None Left and right edge of the grid, as a fraction of the image width (0-1). None uses margin_in on each side. Titles and sources are aligned to the left edge. bottom, top : float | None Bottom and top edge of the grid, as a fraction of the image height measured from the bottom (0-1, like matplotlib). Require height_in. None places the grid between the sheet title and the sources. wspace, hspace : float | None Space between columns / rows, as a fraction of the average column width / average row height (like matplotlib). None uses col_gap_in / row_gap_in. margin_in : float Side margin in inches when left / right are None. col_gap_in, row_gap_in : float Space between columns / rows in inches when wspace / hspace are None. pad_top_in, pad_bottom_in : float Space above the top rule and below the last source line.

    Text

    header_size, header_color, header_weight Style of the sheet title (add_title). title_size, title_color, title_weight Default style of panel titles. subtitle_size, subtitle_color Style of panel subtitles. title_gap_in : float Gap between a panel title block and its table. footer_size, footer_color Default size and color of panel notes, general notes and sources. note_size, note_color : float | None, str | None Size and color of the notes: the ones under each panel (panel(notes=...)) and the general ones (add_note). class SheetStyle:
    """
    Visual parameters of a ``TableSheet``.

    Every field can be changed with ``TableSheet.config_layout`` (or with
    the shortcut ``subplots_adjust``) and passed as a
    keyword argument of the ``TableSheet`` constructor.

    Size
    ----
    font_family : str
        Font of titles, notes and sources. A comma-separated list is
        accepted; the first installed font is used, with a fallback to
        ``DejaVu Sans``.
    width_in : float
        Image width in inches.
    height_in : float | None
        Image height in inches. ``None`` (default) computes it from the
        content. When set, the image has exactly this height: the source
        lines are anchored to the bottom, panels that do not fit are
        scaled down keeping their proportions, and free space is
        distributed according to ``valign``. For a 16:9 slide use
        ``width_in=13.33, height_in=7.5``.
    valign : {"top", "center", "bottom"}
        Where the panels sit when ``height_in`` leaves free space.
    dpi : int
        Resolution of rendered tables and of the exported image.

    Spacing (``subplots_adjust`` semantics)
    ---------------------------------------
    The panels live in a grid. ``left``, ``right``, ``bottom``, ``top``,
    ``wspace`` and ``hspace`` work like ``matplotlib.pyplot.subplots_adjust``.
    ``None`` means *automatic* and falls back to the inch-based values.

    left, right : float | None
        Left and right edge of the grid, as a fraction of the image width
        (0-1). ``None`` uses ``margin_in`` on each side. Titles and
        sources are aligned to the left edge.
    bottom, top : float | None
        Bottom and top edge of the grid, as a fraction of the image
        height measured from the bottom (0-1, like matplotlib). Require
        ``height_in``. ``None`` places the grid between the sheet title
        and the sources.
    wspace, hspace : float | None
        Space between columns / rows, as a fraction of the average column
        width / average row height (like matplotlib). ``None`` uses
        ``col_gap_in`` / ``row_gap_in``.
    margin_in : float
        Side margin in inches when ``left`` / ``right`` are ``None``.
    col_gap_in, row_gap_in : float
        Space between columns / rows in inches when ``wspace`` /
        ``hspace`` are ``None``.
    pad_top_in, pad_bottom_in : float
        Space above the top rule and below the last source line.

    Text
    ----
    header_size, header_color, header_weight
        Style of the sheet title (``add_title``).
    title_size, title_color, title_weight
        Default style of panel titles.
    subtitle_size, subtitle_color
        Style of panel subtitles.
    title_gap_in : float
        Gap between a panel title block and its table.
    footer_size, footer_color
        Default size and color of panel notes, general notes and sources.
    note_size, note_color : float | None, str | None
        Size and color of the notes: the ones under each panel
        (``panel(notes=...)``) and the general ones (``add_note``).
        ``None`` uses ``footer_size`` / ``footer_color``.
    source_size, source_color : float | None, str | None
        Size and color of the source lines (``add_source``). ``None``
        uses ``footer_size`` / ``footer_color``.
    line_spacing : float
        Line height as a multiple of the font size.
    wrap_text : bool
        Wrap titles and notes to the width of their cell.

    Horizontal rules
    ----------------
    line_color : str
        Color of both rules.
    line_width : float
        Thickness of both rules, in points.
    top_line, bottom_line : bool
        Show the rule above the content / above the sources.

    Panels
    ------
    background : str
        Canvas color.
    scale : {"uniform", "fit", "natural"}
        How panel images are scaled (each panel can override it with
        ``panel(scale=...)``). ``"uniform"`` uses the same scale for all
        tables (same visual font size), the largest that fits every cell.
        ``"fit"`` stretches the panel to its cell width. ``"natural"``
        keeps the real size (``px / dpi`` inches) and only shrinks panels
        that do not fit. Image panels treat ``"uniform"`` as
        ``"natural"``, so a chart is never stretched unless it is set to
        ``"fit"``.
    resampling : {"lanczos", "bicubic", "bilinear", "nearest"}
        Filter used to resize table images (done once with PIL).
    table_font_px : int
        Base font size of rendered tables in CSS pixels. Styles set with
        ``style_table(font_size=...)`` override it.
    zebra : bool
        Alternate row shading (``#f5f5f5`` on odd rows) in the base table
        CSS.
    """

    font_family: str = DEFAULT_FONT_FAMILY
    width_in: float = 8.0
    height_in: float | None = None
    valign: VAlign = "top"
    dpi: int = DEFAULT_DPI

    left: float | None = None
    right: float | None = None
    bottom: float | None = None
    top: float | None = None
    wspace: float | None = None
    hspace: float | None = None
    margin_in: float = 0.45
    col_gap_in: float = 0.30
    row_gap_in: float = 0.30
    pad_top_in: float = 0.15
    pad_bottom_in: float = 0.20

    header_size: float = 18
    header_color: str = "#111111"
    header_weight: str = "bold"
    title_size: float = 12
    title_color: str = "#111111"
    title_weight: str = "bold"
    subtitle_size: float = 9
    subtitle_color: str = "#666666"
    title_gap_in: float = 0.08
    footer_size: float = 9
    footer_color: str = "#666666"
    note_size: float | None = None
    note_color: str | None = None
    source_size: float | None = None
    source_color: str | None = None
    line_spacing: float = 1.5
    wrap_text: bool = True

    line_color: str = "#D9D9D9"
    line_width: float = 1.2
    top_line: bool = True
    bottom_line: bool = True

    background: str = "white"
    scale: ScaleMode = "uniform"
    resampling: Resampling = "lanczos"
    table_font_px: int = 14
    zebra: bool = True

    def __post_init__(self) -> None:
        if self.width_in <= 0:
            raise ValueError("width_in must be > 0.")
        if self.height_in is not None and self.height_in <= 0:
            raise ValueError("height_in must be > 0 (or None for automatic).")
        if self.dpi <= 0:
            raise ValueError("dpi must be > 0.")
        if self.table_font_px <= 0:
            raise ValueError("table_font_px must be > 0.")
        if self.line_spacing <= 0:
            raise ValueError("line_spacing must be > 0.")
        for name in ("note_size", "source_size"):
            value = getattr(self, name)
            if value is not None and value <= 0:
                raise ValueError(
                    f"{name} must be > 0 (or None to use footer_size)."
                )
        for name, allowed in (
            ("valign", VALIGNS),
            ("scale", SCALE_MODES),
            ("resampling", RESAMPLINGS),
        ):
            if getattr(self, name) not in allowed:
                raise ValueError(
                    f"{name} must be one of {allowed}, "
                    f"got {getattr(self, name)!r}."
                )

        for name in ("left", "right", "bottom", "top"):
            value = getattr(self, name)
            if value is not None and not 0 <= value <= 1:
                raise ValueError(f"{name} must be between 0 and 1.")
        if None not in (self.left, self.right) and self.left >= self.right:
            raise ValueError("left must be smaller than right.")
        if None not in (self.bottom, self.top) and self.bottom >= self.top:
            raise ValueError("bottom must be smaller than top.")

        for name in ("wspace", "hspace"):
            value = getattr(self, name)
            if value is not None and value < 0:
                raise ValueError(f"{name} must be >= 0.")
        if self.line_width < 0:
            raise ValueError("line_width must be >= 0.")
        for name in (
            "margin_in",
            "pad_top_in",
            "pad_bottom_in",
            "col_gap_in",
            "row_gap_in",
            "title_gap_in",
        ):
            if getattr(self, name) < 0:
                raise ValueError(f"{name} must be >= 0.")
        if 2 * self.margin_in >= self.width_in:
            raise ValueError("margin_in is too large for width_in.")

class PlaywrightRenderer:
    """
    Render HTML documents to images with a headless Chromium browser.

    All documents of a call share **one** browser instance, which makes a
    grid of tables almost as fast as a single table (launching the browser
    is the expensive part).

    Parameters
    ----------
    chrome_path : str | None, default None
        Path to a Chromium-based executable. If given, ``channels`` is
        ignored.
    channels : Sequence[str | None], default ``("chrome", "msedge", "chromium", None)``
        Browser channels tried in order. ``None`` is the Chromium bundled
        with Playwright. The first one that launches is remembered.
    timeout_ms : int, default 30000
        Timeout of page operations.
    launch_args : Sequence[str], default ()
        Extra command-line arguments for the browser.

    Attributes
    ----------
    launch_count : int
        Number of browsers launched by this instance.

    Notes
    -----
    Requires ``playwright``. If no browser is found, install one with
    ``python -m playwright install chromium`` or use Chrome/Edge.

    Examples
    --------
    >>> renderer = PlaywrightRenderer(chrome_path=r"C:\\Program Files\\...\\chrome.exe")
    >>> sheet = TableSheet(df, renderer=renderer)
    """

    chrome_path: str | None = None
    channels: Sequence[str | None] = DEFAULT_BROWSER_CHANNELS
    timeout_ms: int = 30_000
    launch_args: Sequence[str] = ()
    launch_count: int = field(default=0, init=False)
    cache_token: str = field(default="playwright", init=False)
    _working_channel: Any = field(default=None, init=False, repr=False)
    _has_working_channel: bool = field(default=False, init=False, repr=False)

    def __call__(
        self,
        documents: Sequence[str],
        dpi: int,
    ) -> list[np.ndarray]:
        """
        Render documents to RGB ``uint8`` arrays.

        Parameters
        ----------
        documents : Sequence[str]
            Complete HTML documents (see ``build_document``).
        dpi : int
            Output resolution. One CSS pixel becomes ``dpi / 96`` pixels.

        Returns
        -------
        list[numpy.ndarray]
            One image per document, in the same order.
        """
        if not documents:
            return []
        return _run_isolated(lambda: self._render(documents, dpi))

    # -- internals ----------------------------------------------------

    def _render(
        self,
        documents: Sequence[str],
        dpi: int,
    ) -> list[np.ndarray]:
        try:
            from playwright.sync_api import sync_playwright
        except ImportError as error:
            raise ImportError(
                "Playwright is required to render tables. "
                "Install it with 'pip install playwright'."
            ) from error

        images: list[np.ndarray] = []

        with sync_playwright() as playwright:
            browser = self._launch(playwright)
            try:
                context = browser.new_context(
                    device_scale_factor=dpi / 96,
                    bypass_csp=True,
                )
                page = context.new_page()
                page.set_default_timeout(self.timeout_ms)

                for index, document in enumerate(documents):
                    try:
                        images.append(self._screenshot(page, document))
                    except Exception as error:
                        raise RuntimeError(
                            f"Could not render document {index}: "
                            f"{type(error).__name__}: {error}"
                        ) from error
            finally:
                browser.close()

        return images

    def _launch(self, playwright: Any) -> Any:
        """Launch the first available browser, remembering which one."""
        if self.chrome_path:
            attempts: list[tuple[str | None, str | None]] = [
                (None, self.chrome_path)
            ]
        else:
            channels = list(self.channels)
            if self._has_working_channel and self._working_channel in channels:
                channels.remove(self._working_channel)
                channels.insert(0, self._working_channel)
            attempts = [(channel, None) for channel in channels]

        errors: list[str] = []
        for channel, executable in attempts:
            options: dict[str, Any] = {
                "headless": True,
                "args": list(self.launch_args),
            }
            if executable:
                options["executable_path"] = executable
            elif channel:
                options["channel"] = channel

            try:
                browser = playwright.chromium.launch(**options)
            except Exception as error:
                first_line = (str(error).strip().splitlines() or [""])[0]
                label = executable or channel or "bundled chromium"
                errors.append(
                    f"  - {label}: {type(error).__name__}: {first_line}"
                )
                continue

            self.launch_count += 1
            self._working_channel = channel
            self._has_working_channel = True
            return browser

        raise RuntimeError(
            "No Chromium-based browser could be launched.\n"
            + "\n".join(errors)
            + "\nInstall one with 'python -m playwright install chromium', "
            "install Chrome/Edge, or pass PlaywrightRenderer(chrome_path=...)."
        )

    def _screenshot(self, page: Any, document: str) -> np.ndarray:
        from PIL import Image

        page.set_content(document, wait_until="load")
        page.evaluate(
            "async () => { await document.fonts.ready; return true; }"
        )

        table = page.locator(f"#{TABLE_ELEMENT_ID}")
        box = table.bounding_box()
        if not box or box["width"] <= 0 or box["height"] <= 0:
            raise RuntimeError("the table is empty (zero size).")

        page.set_viewport_size(
            {
                "width": math.ceil(box["width"]) + 20,
                "height": math.ceil(box["height"]) + 20,
            }
        )
        png = table.screenshot(type="png")

        with Image.open(io.BytesIO(png)) as image:
            return np.asarray(image.convert("RGB")).copy()

    class RenderCache:
    """
    Thread-safe LRU cache of rendered table images, limited by memory.

    Tables are cached by *content* (the HTML that is rendered), not by
    object identity. Re-running a notebook cell that rebuilds the same
    table, or changing only a title or a gap, therefore never launches the
    browser again.

    Parameters
    ----------
    max_mb : float, default ``DEFAULT_CACHE_MB``
        Memory budget in megabytes. ``0`` disables caching.

    Attributes
    ----------
    hits, misses : int
        Lookup counters.

    Examples
    --------
    >>> sheet = TableSheet(df, cache=RenderCache(max_mb=0))  # no cache
    """

    def __init__(self, max_mb: float = DEFAULT_CACHE_MB) -> None:
        if max_mb < 0:
            raise ValueError("max_mb must be >= 0.")
        self.max_bytes = int(max_mb * 1024 * 1024)
        self.hits = 0
        self.misses = 0
        self._items: OrderedDict[str, np.ndarray] = OrderedDict()
        self._bytes = 0
        self._lock = threading.Lock()

    def get(self, key: str) -> np.ndarray | None:
        """Return the cached image or ``None``."""
        with self._lock:
            image = self._items.get(key)
            if image is None:
                self.misses += 1
                return None
            self._items.move_to_end(key)
            self.hits += 1
            return image

    def put(self, key: str, image: np.ndarray) -> None:
        """Store ``image`` (made read-only), evicting least-recent entries."""
        if self.max_bytes == 0 or image.nbytes > self.max_bytes:
            return
        image.flags.writeable = False
        with self._lock:
            previous = self._items.pop(key, None)
            if previous is not None:
                self._bytes -= previous.nbytes
            self._items[key] = image
            self._bytes += image.nbytes
            while self._bytes > self.max_bytes and self._items:
                _, evicted = self._items.popitem(last=False)
                self._bytes -= evicted.nbytes

    def clear(self) -> None:
        """Remove every cached image and reset the counters."""
        with self._lock:
            self._items.clear()
            self._bytes = 0
            self.hits = 0
            self.misses = 0

    @property
    def size_mb(self) -> float:
        """Memory currently used, in megabytes."""
        return self._bytes / (1024 * 1024)

    def __len__(self) -> int:
        return len(self._items)

    def __contains__(self, key: object) -> bool:
        return key in self._items

    def __repr__(self) -> str:
        return (
            f"RenderCache(items={len(self)}, "
            f"size_mb={self.size_mb:.1f}/{self.max_bytes / 1048576:.0f}, "
            f"hits={self.hits}, misses={self.misses})"
        )
