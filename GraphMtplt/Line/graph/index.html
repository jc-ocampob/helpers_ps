    Line Chart¶

    GraphMtplt.graph_line() generates line charts for time series or any indexed dataframe.

    Expected DataFrame¶

    Date          SPX      NASDAQ
2024-01-31    100      150
2024-02-29    105      152
2024-03-31    108      160
    • The index represents the X-axis.
    • The columns represent the data series.

    Customize series labels¶

    In [17]:
    Copied! 
    g = (
    hp.GraphMtplt(df)
    .graph_line(
        tickers=[
            "return",
            "nav"
        ],
        axis_side=["left", "right"],
        labels=[
            "Return",
            "Net Asset Value"
        ],
    )
    .add_legend(show=True)
)
    g = ( hp.GraphMtplt(df) .graph_line( tickers=[ "return", "nav" ], axis_side=["left", "right"], labels=[ "Return", "Net Asset Value" ], ) .add_legend(show=True) )
